# کافه معدن — Landing Final 3

این پوشه نسخهٔ مستقل لندینگ فعلی به‌همراه بک‌اند موجود در `server/` است. فایل‌های فرانت اصلی پروژهٔ والد دست‌نخورده مانده‌اند.

## اجرا

از پوشهٔ `server` اجرا کن:

```powershell
npm start
```

سرور از تنظیمات `server/.env` برای پورت، MongoDB و JWT استفاده می‌کند. این فایل در Git نادیده گرفته می‌شود.

## اتصال‌های فعال

- فرم ثبت‌نام `POST /register` را با `name`، `phone` و `coupon` صدا می‌زند.
- شمارش بازدید `POST /analytics/visit` را صدا می‌زند.
- فرانت در صورت دریافت `paymentUrl` معتبر از پاسخ ثبت‌نام به آن هدایت می‌شود.

در بک‌اند موجود، ثبت‌نام و ذخیرهٔ اطلاعات پیاده‌سازی شده؛ ساخت لینک پرداخت یا اتصال به درگاه در کد/API موجود نیست. بنابراین پس از ثبت موفق، کاربر پیام ذخیره‌شدن ثبت‌نام را می‌بیند و به درگاه هدایت نمی‌شود.
